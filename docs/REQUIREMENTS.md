# 附件功能覆盖说明

附件概要文字写有“34个功能点”，明细表实际列出 35 行，本实现按 35 项明细执行。附件示例公式中的 `#VALUE!` 和 `#NAME?` 属于原表错误，不作为业务规则。

| 一级模块 | 已实现内容 |
| --- | --- |
| 客户与渠道 | 客户档案、三类渠道、车型与区域授权、账期、授信额度、客户专属价与等级价、价格保密 |
| 计划管理 | 月度滚动计划、按周明细、草稿/审核/撤回/退回/生效、计划订单限量和计划执行率 |
| 订单管理 | 正常、预付、新产品、计划、临时订单；邦邦转交三磊；主子单；状态、物流和分批收货 |
| 库存与供应商 | 真实库存、虚拟库存、预占、库存流水、仓间移库、产品与供应商档案、订单预占 |
| 销售结算 | 应收占用、微信预付款、多笔到账、发票、运费、调整款和结算状态 |
| 售后服务 | 退货、索赔、发错货、更换、市场质量反馈；产品质保参数 |
| 系统设置 | 员工与客户子账号、角色菜单和客户数据隔离、审计日志 |
| 专项一 | 预付比例门槛、逐批金额上限、最多批次、预付款/发货余额一致性、未完成订单跟踪 |
| 专项二 | 预付款与客户等级优先的多维度加权公平分配、最小包装取整、人工确认和审计 |
| 专项三 | 同客户同结算周期自动归并总单，按车型拆分保留子单，可展开查看全部明细 |

正式微信资质、真实商户扣款和正式小程序审核发布依赖外部账号，不属于当前代码环境可直接生成的产物。
